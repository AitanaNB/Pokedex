#Funcionamiento Bot de Telegram

-Para encender el bot de telegram hay que correr el archivo TelegramAPI.py, una vez encendido simplemente es hablarle por Telegram

-El bot esta integrado dentro del sistema de la APP, por lo que se comunica directamente con los controladores, por eso no hay que tener la web corriendo ni ninguna API

-Lo que determina que Bot de Telegram es, es el TOKEN en la parte superior del archivo TelegramAPI.py

-Para la funcionalidad de vincular la cuenta, si es necesario tener la web corriendo (run.py), pero no el bot
